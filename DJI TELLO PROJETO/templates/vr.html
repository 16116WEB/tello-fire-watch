Modo imersivo (Quest)

Stream da camera numa tela flutuante dentro do headset, telemetria como HUD e os controllers mapeados para mover o drone. Precisa de HTTPS para o navegador liberar o WebXR.

WebXR nao esta disponivel aqui. Confirme que esta acessando por HTTPS (rode python generate_cert.py e abra https://<ip-do-pc>:5000/vr), ou instale a extensao "Immersive Web Emulator" no Chrome desktop pra testar sem o headset.
